# V32 画布结果恢复与管理员提示词脱敏

## 基线

- 基于 V31 分支 `codex/v31-prompt-safety-risk-monitoring`、源码 HEAD `8db252e`（标签 `v1.0.11`）。
- 不回退、不覆盖 V31；生产部署前保留 V31 回滚镜像。

## 证据与根因

- 生产日志显示上游图片请求 HTTP 200、图片下载 HTTP 200，任务最终为 `succeeded` 且 `delivered_quantity=1`，说明上游生成、下载、扣费与持久化链路已完成。
- 智能画布在收到成功终态后立即读取 `/api/v1/generation-tasks/{task_id}/media`。当任务终态先于媒体列表在独立请求中可见时，V31 客户端把空媒体列表当作完成，清理待处理节点并显示无输出；页面恢复读取也只有一次机会。
- 管理员任务投影复用用户安全投影，继续返回 `prompt`，管理员任务页面同时渲染该字段。

## 修复目标

1. 成功任务必须在受控退避窗口内等到已交付媒体可见后再完成画布节点；不重提上游、不重复扣费、不重复写入。
2. 页面切换或重新进入画布时，已成功任务继续通过同一有界媒体恢复策略显示。
3. 管理员活动/历史任务接口与两套管理员页面均不返回或显示用户实际提示词。

## 验证

- 新增画布成功终态媒体延迟可见回归测试。
- 新增管理员任务 API 提示词不泄露回归测试，并检查管理员页面不渲染提示词列。
- 运行相关后端/UI 定向测试、JS/Python 语法检查、前端构建、`git diff --check`；部署前执行容器健康/就绪及 Web/Worker 摘要一致性核验。

## 数据与回滚

- 仅读取既有任务和媒体；不创建新上游任务，不改额度流水，不删除历史媒体。
- 无数据库迁移。
- 失败时回滚到 `creative-studio:single-host-rollback-v32`（V31 镜像）。
