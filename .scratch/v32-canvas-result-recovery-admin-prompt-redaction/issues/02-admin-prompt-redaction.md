# 管理员任务明细提示词脱敏

Type: task
Status: resolved

## 问题

管理员活动/历史任务投影复用包含 `prompt` 的用户投影，前端也渲染实际提示词。

## 处理

管理员专用投影移除 `prompt` 字段，活动/历史两个管理员页面移除提示词展示；用户任务接口保持现有功能。

## Comments

- 不修改数据库中的历史提示词，只限制管理员任务明细 API/UI 的输出。

## Answer

V32 管理员任务接口投影和两套任务页面均移除实际 `prompt` 字段；数据库历史提示词未删除，普通用户任务接口保持原有行为。相关 API 与 UI 回归测试通过。
