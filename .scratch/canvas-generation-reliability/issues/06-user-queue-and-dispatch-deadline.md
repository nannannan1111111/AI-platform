# 用户生图排队与处理时限

Type: task
Status: resolved

## Answer

- 每个账户最多保留 20 个活动图片名额，`quantity=4` 按 4 个名额计算。
- 同一账户同时最多 2 个批次任务向上游发送请求，其余任务按提交时间排队。
- `queued` 显示“正在排队”，获得用户与上游并发槽后显示“正在生图”。
- 二十分钟任务时限从 Worker 准备发送首次 Provider 请求时开始，排队等待不计入。
- 多 Worker 通过 PostgreSQL advisory lock 共享每账户 2 个执行槽，并在锁内二次检查，避免并发绕过。
