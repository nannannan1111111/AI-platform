# V30 数字输入兼容与乐云图标

基于 V29 提交 `70f2311`，统一数字输入接口的金额/额度字符串边界，并将提供的乐云图标接入主站、智能画布和兼容画布页面。其他业务逻辑、额度流水、生成任务和历史数据保持不变。

## 验收标准

- 浏览器数字输入提交到金额/额度字符串接口时不再出现 `Input should be a valid string`。
- 旧客户端提交 JSON 数字时，后端将其规范化为字符串后沿用既有金额精度校验。
- 主站、智能画布和 classic 兼容地址均声明乐云 favicon/apple-touch-icon。
- V30 镜像基于 V29 运行时构建并通过部署健康检查。
