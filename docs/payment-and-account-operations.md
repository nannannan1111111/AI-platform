# 支付异常与账户找回运维手册

## 当前安全边界

- 易支付兼容 Adapter 已支持下单、MD5 验签、金额/PID/支付方式校验，以及支付成功事件的幂等入账。
- 整笔拒付的领域与数据库事实已经支持幂等冲正，冲正后余额允许为负；生产运行时尚未接入任何未经实际网关文档和沙箱验证的拒付通知。
- 退款、部分退款与拒付不能根据支付成功通知推断，也不能通过修改订单状态或直接执行 SQL 代替渠道事实。
- 在选定网关不能提供正式事件文档、签名规则、稳定事件 ID 和沙箱前，在线支付必须保持关闭；管理员人工充值可以继续用于内部验收。

## 密码找回

用户在 `/forgot-password` 提交邮箱。接口对已注册、未注册和暂时无法投递的邮箱统一返回 `202`，原始令牌不会出现在响应或日志中。

- 令牌使用密码学随机值，数据库只保存 SHA-256 摘要。
- 每个用户最多保留一个有效令牌；重发会替换旧令牌。
- 有效期为 30 分钟，只能使用一次。
- 成功重置后撤销该用户的全部登录会话。
- 请求按规范化邮箱和可信客户端 IP 分别限流；默认每小时 `3` 次/邮箱、`5` 次/IP。

## 每日支付对账

从支付渠道导出目标 UTC 时间窗内的事件，转换为 UTF-8 CSV：

```csv
event_type,payment_provider,provider_event_id,order_id,amount_cny,occurred_at
payment_success,epay,trade-1001,6d4d9e4f-0000-0000-0000-000000000001,10.00,2026-08-17T01:02:03Z
chargeback,epay,dispute-2001,6d4d9e4f-0000-0000-0000-000000000001,10.00,2026-08-17T07:08:09Z
```

`event_type` 允许 `payment_success`、`chargeback`、`refund`、`partial_refund`。后两类会被明确报告为尚不支持，绝不会自动改账。

在只读运维环境运行：

```powershell
Set-Location backend
& .venv/Scripts/python.exe scripts/reconcile_payment_events.py `
  --channel-csv C:\secure-ops\payment-events.csv `
  --from 2026-08-16T00:00:00Z `
  --until 2026-08-18T00:00:00Z
```

生产中使用 48 小时滚动窗口覆盖渠道时间与本地接收时间的边界差异。工具只读数据库并输出 JSON：

- 退出码 `0`：事件身份、订单和金额完全一致。
- 退出码 `2`：存在渠道单边事件、本地单边事件、金额/订单不一致，或退款类型尚不支持；必须创建运营工单并阻止自动结案。
- 其他非零退出：输入、数据库或执行失败；对账视为失败，不能当作无差异。

渠道导出包含支付标识，应存放在受限运维目录，不上传仓库、不通过聊天工具传输，并按财务保留策略处理。

## 退款、部分退款和拒付人工流程

在自动 Adapter 完成前，每项资金异常必须由两名不同人员复核：

1. 经办人创建不可删除的工单，记录本地订单 ID、渠道交易号、金额、币种、原因和渠道原始状态。
2. 复核人独立查询本地订单与渠道后台，确认 PID、支付渠道、整笔金额、原支付成功事实和当前退款/争议状态。
3. 涉及现金退款时，仅在渠道后台执行退款；不得先改本地数据库，不得把“生成任务额度释放”当作现金退款。
4. 重新导出渠道事件并运行每日对账。`refund`、`partial_refund` 或缺失的 `chargeback` Adapter 必须保持开放工单，由研发根据该渠道的正式签名事件接入后追加本地冲正事实。
5. 自动事件接入后，使用渠道稳定事件 ID 幂等重放；确认账务新增一条相反方向记录、订单投影正确且重复通知不二次冲正。
6. 复核人关闭工单，附上脱敏对账结果、渠道结果和本地账务 posting ID。任何差异未消除时不得关闭。

严禁直接 `UPDATE recharge_orders`、删除账务记录、复用另一个渠道的签名密钥，或使用自造事件 ID 冒充渠道事实。

## 自动 Adapter 上线门槛

选定真实支付网关后，必须取得并在沙箱验证：

- 支付成功、整笔退款、部分退款、拒付及撤销拒付的事件类型与乱序规则；
- 原始请求体签名、时间戳/重放窗口、密钥轮换、商户身份和金额精度；
- 每类事件的稳定唯一键，以及重复投递的官方保证；
- 部分退款累计不超过原支付金额、退款失败与异步完成语义；
- 错签名、错 PID、错币种、错金额和未知订单的失败响应。

完成 Adapter、沙箱回归和告警接入之前，本任务的支付自动化部分不能标记为生产完成。
